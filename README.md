# 错题分析与管理系统（MVP）

为初中到高中学生设计的错题记录、分析与复习 Web 应用（PWA，可加到 iPad 主屏幕当 App 用）。

## 功能
- **录入**：拍照/相册多选 → 自动压缩 → 选科目/年级/题型/错因/知识点/来源 → 填题干、错答、正确答案、解析。
- **错题本**：按科目 / 年级 / 掌握状态筛选，详情查看、编辑、删除。
- **分析**：总数与掌握情况，按科目、年级、题型、错因的条形分布。
- **复习重做**：按遗忘曲线排出"今日复习"，重做时隐藏答案，答完揭晓答案与思路，连续答对标记为"已掌握"。
- **我的**：切换当前年级（初一→高三无缝延续）、导出/导入备份（防丢）、清空。

## 技术
- 纯前端：HTML + CSS + 原生 JS（ES Module）。
- 本地存储：IndexedDB（数据存在本机，图片自动压缩）。
- PWA：manifest + Service Worker，可离线、可加到主屏幕。

## 部署
本仓库直接作为 GitHub Pages 站点根目录即可（`Settings → Pages → 选 main 分支 / root`）。
所有资源使用相对路径，兼容子路径部署。

## 数据安全
错题数据默认只存在使用者本机浏览器（IndexedDB）。请定期在"我的"页点"导出备份"存到 iCloud / 文件 App 防丢。
